01 • CLINICAL MOTIVATION

The Mental Health Crisis in Higher Education

60%+

Severe Anxiety & Strain

Of university students report acute academic pressure, sleep deprivation, or emotional burnout during their degrees.

< 15%

Underutilized Centers

Seek institutional care due to social stigma, fear of peer judgment, and privacy concerns regarding academic penalization.

11PM - 4AM

Midnight Crisis Window

Psychological distress and acute panic attacks peak late at night when university counseling centers are completely closed.

Why Traditional Campus Counseling Fails:

  • 3 to 14 Days Waiting Queues: Bureaucratic appointment delays fail during acute crises.
  • Static Survey Blindspot: Traditional questionnaires (PHQ-9) capture only one static moment, missing daily oscillations between sleep and strain.
  • Purely Reactive Model: Support occurs only after academic failure or breakdown rather than through early proactive detection.

12 • SECURITY & CLOUD INTEGRATION

Enterprise Security, PyJWT & The Brevo HTTPS Driver

Bcrypt & Stateless JWT

  • Bcrypt (12 Salt Rounds): 4,096 Blowfish iterations render GPU brute-force attacks impossible.
  • PyJWT: Signed with HS256, 24-hour expiration. Stateless tokens eliminate server session memory bottlenecks.

Why Brevo REST API over SMTP?

  • Cloud Port Blocking: Render and AWS block outbound TCP ports 25, 465, and 587.
  • HTTPS Port 443: Brevo transmits OTP verification over standard HTTPS, which is never blocked.
  • MongoDB TTL Index: Auto-deletes expired OTP documents after exactly 5 minutes.

15 • ENGINEERING LESSONS

Key Engineering Challenges Overcome

1. Cloud SMTP Port Blocking

Problem: Render blocked outbound SMTP ports 25, 465, and 587 (`[Errno 101] Network unreachable`).
Solution: Engineered a custom Brevo REST API email client transmitting OTP payloads over HTTPS port 443.

2. Google Places API Quota Limits (HTTP 429)

Problem: Unbilled daily quota exhaustion during high-frequency testing caused API dropouts.
Solution: Built a local MongoDB fallback database with Haversine filtering strictly capped to ≤ 100 km.

3. Local LLM Latency (15-30s)

Problem: Running local models on consumer laptops caused severe response lag.
Solution: Integrated Groq LPUs running Llama 3.3 70B, reducing inference time to sub-400 milliseconds.
